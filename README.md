# lab1_cpp

Консольное приложение на C++, отображающее движущуюся вертикальную линию из символов.

## Технологии
- C++
- WinAPI
- Visual Studio 2026

## Ветки
- `about` — общая информация о проекте.
- `develop` — основная ветка разработки.
- `lab-01` — стабильная версия лабораторной работы №1 после проверки преподавателем.

## Сборка и запуск
1. Открыть `lab1_cpp.slnx` в Visual Studio 2026.
2. Выбрать конфигурацию `Debug` или `Release` и платформу `x64`.
3. Выполнить сборку решения и запустить приложение.

## Использование
Без аргументов программа запрашивает параметры интерактивно.

Также можно передать аргументы командной строки:
- скорость: от 1 до 30 символов в секунду;
- длина линии: от 1 до 30 символов;
- режим эпилепсии: `Y` или `N`.

Для справки: `--help` или `/?`.
